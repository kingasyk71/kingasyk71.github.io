# Штаб — личное приложение

PWA на GitHub Pages + Supabase. Ставится на экран телефона, у каждого свой аккаунт и свои данные.

- `index.html` — приложение.
- `epochs.js` — «Хроники»: 12 эпох, каждые 3 дня новая (палитра, шрифт, орнамент, иллюстрация, история и 6 фактов). Режимы: личный (дела, спорт, настроение, заметки) и рабочий (плюс контент, клиенты, деньги).
- `scenes.js` — живые многослойные сцены эпох (параллакс, частицы, живые детали).
- `dos.js` — Дос: объёмный персонаж, эмоции, реакции, костюмы эпох, звук.
- `fx.js` — анимации: пружины, каскады, конфетти, наклон карточек, шторки, таб-бар, заставка эпохи.
- `backend.js` — вход по почте и паролю, синхронизация через Supabase, файлы в Storage.
- `config.js` — адрес проекта Supabase и публичный anon-ключ.
- `setup.sql` — таблица, правила доступа (каждый видит только своё), realtime, хранилище файлов.
- `sw.js`, `manifest.webmanifest`, `icons/` — установка на телефон и работа без сети.

Личные данные в репозиторий не попадают: они только в Supabase.

## RPG-режим и 3D-герой
- `rpg.js` — игровой слой (кат-сцена, создание героя, HUD, квесты, рейды, лут, уровни). Сборка вшивает его внутрь основного скрипта.
- `hero3d.js` — движок героя (three.js + @pixiv/three-vrm), собран esbuild.
- `hero.vrm` — 3D-модель по умолчанию: пример VRoid от pixiv Inc. (VRM Public License 1.0: использование, изменение и распространение разрешены, указывать автора не обязательно). Текстуры ужаты. Свою модель из VRoid Studio можно положить на место этого файла.
